# Diário de Produção — LM
Programação semanal e diário de produção das obras, com exportação para o Excel no modelo PROGRAMAÇÃO SEMANAL da LM.

- **Programação da semana**: atividades por grupo (Terraplanagem, Drenagem, Pavimentação...), unidade, quantidade do mês e programado por dia. Dá para copiar da semana anterior.
- **Diário do dia**: o engenheiro lança só o realizado de cada atividade, o clima (manhã/tarde/noite), atividades não programadas e observações.
- **Semana / Exportar**: visão da semana com aderência (real/prog) e botão para gerar o Excel no modelo LM (uma obra ou todas, uma aba por obra).
- Dados no Firebase do Controle LM, em coleções próprias (`diario_obras`, `diario_semanas`) — não mexe nos outros sistemas.
- Abrir com `?local` no fim do endereço usa só o navegador atual, para testes, sem mexer nos dados da equipe.
